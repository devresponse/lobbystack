## Check the deployment settings it named

These need no code, only a look at the admin and worker services:

- `APP_BASE_URL` is set on the worker to the dashboard's address. It is what names the brand in the worker's texts and emails; `BRAND_REQUIRED=true` makes either service refuse to start without a brand.
- `EMAIL_FROM` is a bare address, unless a fixed sender name is wanted: a name in it wins over the brand's.
- The migrate log of the deploy with migration `0101` says `Business snapshots: N refreshes queued`, not `Skipping the phone number snapshot refresh`. Data migrations skip themselves unless the migrator bypasses row-level security.
- `OTP_HASH_SECRET` has the same value on both services: the admin hashes keypad PINs and the worker checks them.
