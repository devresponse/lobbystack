La page **Réglages** > **Code QR** crée des affiches à imprimer avec un code QR qui ouvre votre [profil public](/fr/settings/public-profile). Placez-les sur votre porte, votre comptoir ou vos tables. Le code est créé dans votre navigateur à partir de l'adresse de la page, et rien n'est enregistré.

Tous les membres de votre entreprise peuvent imprimer les affiches.

## Imprimer une affiche

<Steps>
  <Step title="Ouvrir les réglages du code QR">
    Allez dans **Réglages** > **Code QR**. **Ouvre** indique l'adresse que le code ouvre.
  </Step>
  <Step title="Choisir un modèle">
    **Signal** est une affiche jaune. **Réception** est blanche et utilise moins de toner. **Nuit** est noire, pour les pièces sombres.
  </Step>
  <Step title="Écrire le message">
    Tapez le titre de l'affiche dans **Message**, jusqu'à 80 caractères. Appuyez sur Entrée pour commencer une nouvelle ligne. Le texte rapetisse pour tenir dans le format choisi.
  </Step>
  <Step title="Choisir un format">
    Chaque format s'imprime sur du papier A4 : une affiche **Pleine page**, deux affiches **Demi-page** (A5), quatre affiches **Quart de page** (A6) ou huit **Cartes** (A7), avec des lignes pointillées pour les découper. Chaque format indique la largeur de son code imprimé et la distance à laquelle il se scanne.
  </Step>
  <Step title="Choisir ce qui va au centre du code">
    Sous **Au centre du code**, choisissez **Nom** pour mettre le nom LobbyStack au centre du code, **Logo** pour son logo, ou **Rien**.
  </Step>
  <Step title="Choisir la langue de l'affiche">
    Sous **Langue**, choisissez la langue des mots imprimés sur l'affiche. Elle peut être différente de celle de votre tableau de bord.
  </Step>
  <Step title="Imprimer">
    Cliquez sur **Imprimer**. Dans la fenêtre d'impression, choisissez du papier A4 et imprimez à la taille réelle (100 %), pas **Ajuster à la page**. Chaque affiche garde au moins 5 mm de papier blanc autour d'elle, donc les marges d'une imprimante laser ne la coupent pas.
  </Step>
</Steps>

<Tip>
  Scannez l'affiche imprimée avec deux téléphones avant de l'installer. Le papier mat se scanne mieux que le papier glacé. Pour un PDF, choisissez **Enregistrer au format PDF** dans la fenêtre d'impression.
</Tip>

## Ce que dit l'affiche

- Le nom de votre entreprise.
- Votre message, comme titre.
- « Scannez pour discuter avec nous » quand votre profil public a un clavardage, ou « Scannez pour voir notre page » sinon.
- L'adresse de la page, pour ceux qui préfèrent la taper.
- « Accueil assuré par LobbyStack ».

## Avant la publication de votre profil

Tant que votre profil public n'est pas publié, toute personne qui scanne le code arrive sur une page qui dit qu'elle n'existe pas. La page **Code QR** le signale, et dirige les propriétaires et les administrateurs vers **Profil public** pour le publier. Vous pouvez imprimer les affiches avant : le code ouvre la page dès qu'elle est publiée, car l'adresse ne change pas.

## Télécharger le code seul

Cliquez sur **Code en PNG** ou **Code en SVG** pour télécharger seulement le code, pour vos menus, vos dépliants ou vos propres créations. Le PNG est assez grand pour l'impression, et le SVG reste net à n'importe quelle taille.
